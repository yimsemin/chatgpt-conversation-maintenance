---
name: tidy
description: ChatGPT 대화 정리 세션을 이어받을 때 사용한다. 현재 상태와 다음 행동을 확인하고 에이전트 몫(분류 제안 작성)만 수행한다.
---

1. `npm run brief`를 실행한다. 코드를 탐색하지 않는다.
2. 출력의 "다음"이 `[사용자]`이면 그 행동(화면: 새 대화 확인, 검토 후 적용, 검토 대기 확정, 처음 시작하기의 기준선 만들기 등)을 사용자에게 안내만 하고 멈춘다. 확인·기준선 만들기·적용을 대신하지 않는다.
3. `[에이전트]`이면 표시된 `workflow.js claude-prompt` 명령으로 요청문을 만들고, 그 지시(형식·압축 기준 포함)대로 `proposal.json`을 쓴 뒤 `validate-proposal`로 검증한다. 맞는 프로젝트가 없으면 프로젝트 없음(`suggestedProjectName: null`)이 정상이다. 기준이 모호할 때만 `CLASSIFICATION_WORKFLOW.md`를 읽는다.
4. 다 쓰면 `npm run brief`를 다시 실행해 다음 행동이 `[사용자]`로 넘어갔는지 확인하고, 화면이 자동으로 검토 단계로 넘어가니 요약을 확인해 적용하라고 안내한다.

제안은 승인이 아니다. 원격 변경은 사용자가 화면에서 승인한 것만 실행된다.
